# Руководство пользователя

## Сценарий работы

1. Откройте **http://127.0.0.1:5173**.
2. Перетащите файл или нажмите **«Выбрат файл»**.
3. Дождитесь окончания обработки (прогресс-бар и этапы).
4. Прослушайте запись, отредактируйте текст, при необходимости переименуйте спикеров.
5. Скопируйте или сохраните **TXT**.
6. **«← Новый файл»** — возврат на главную; текущая задача удаляется с сервера.

История прошлых загрузок **не показывается** — сервис одноразового использования «загрузил → получил → ушёл».

## Поддерживаемые форматы

- **Аудио:** MP3, WAV, M4A, OGG и др.
- **Видео:** AVI, MKV, MP4, MOV (используется **первая аудиодорожка**).

Максимальная длительность задаётся администратором (по умолчанию 30 минут).

## Страница результата

| Элемент | Описание |
|---------|----------|
| Плеер | Встроенный плеер браузера (в т.ч. громкость и mute) |
| Список реплик | Клик по метке времени — перемотка; подсветка текущей фразы |
| **Имена спикеров** | Раскрывающийся блок (▼) |
| **Поиск** | Фильтр блоков по слову/фразе (без учёта регистра) |
| **↑ / ↓** | Кнопки справа снизу — быстрый скролл в начало/конец страницы |
| **Пересчитать роли** | Повторная диаризация без повторного ASR |

## Экспорт TXT

- **Диалог** — `Спикер: текст`
- **С таймкодами** — `[00:01:23] Спикер: текст`
- Опция **склеить соседние реплики** одного спикера

## Ошибки

Уведомления показывают **тип** (например, «Длительность», «Аудио») и текст. Код ошибки указан мелким шрифтом для поддержки.

Типичные случаи — см. [TROUBLESHOOTING.md](./TROUBLESHOOTING.md).
